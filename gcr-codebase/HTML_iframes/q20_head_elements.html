HTML Head Elements Demonstration

This HTML document contains all essential <head> elements:

  • <title> - Defines the title shown on the browser tab.
  • <meta> - Supplies metadata (charset, description, author, viewport).
  • <base> - Sets the base URL for resolving relative links.
  • <link> - Links external resources (e.g. favicon, CSS).
  • <style> - Contains document-level CSS styles.
  • <script> - Embeds client-side JavaScript code.
